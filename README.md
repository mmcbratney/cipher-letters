# Cipher Letters

Write-ups of early modern cipher letters (1537-1737) read in part in October and November 2026 by Malcolm McBratney (Brisbane) working with Claude (Anthropic), each first filed, checked and merged in [Cyphersolver](https://github.com/dbourdeau/cyphersolver). The Ridolfi letter of 1646 is Brice Dudout's reading, written up with his credit first.

Site: https://mmcbratney.github.io/cipher-letters/

Every figure comes from the merged Cyphersolver files. No archive images are copied; pages link to the archives' records. Text CC BY 4.0.
